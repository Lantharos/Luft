Everything here is in Settings, under **Accessibility**. The lock and login screens have an accessibility menu too, so you can turn things on before signing in.

## Seeing

| Option | Does |
| --- | --- |
| Screen reader | Reads the screen aloud with Orca. <kbd>Alt</kbd>+<kbd>Super</kbd>+<kbd>S</kbd> turns it on or off |
| Zoom | Magnifies the screen, from 1.25 to 8 times. <kbd>Alt</kbd>+<kbd>Super</kbd>+<kbd>8</kbd> turns it on, and <kbd>Alt</kbd>+<kbd>Super</kbd>+<kbd>=</kbd> and <kbd>-</kbd> zoom |
| Large text | Makes text 125% |
| High contrast | Stronger edges and colours across the desktop and apps |
| Reduce motion | Fades instead of sliding and zooming |
| Cursor size | Up to four times the usual size |

## Reduced motion

Luft has two separate choices:

- **Reduce motion**, here, keeps animation but takes out the movement. Slides and zooms become fades, springs lose their bounce, and windows no longer fly to the taskbar when minimized. Gestures still follow your fingers.
- **Animations**, under Appearance, turns animation off entirely, so everything changes at once.

Apps are told about either one, so they can follow it too.

## Typing

| Option | Does |
| --- | --- |
| On-screen keyboard | Shows a keyboard on screen when you type. On a touchscreen, it also appears when you tap a text field, or swipe up from the bottom edge |
| Sticky keys | Press <kbd>Ctrl</kbd>, <kbd>Shift</kbd> and the like one after another instead of together |
| Slow keys | Keys only count after being held for a moment |
| Bounce keys | Ignores a key pressed again too quickly |

## Pointing

| Option | Does |
| --- | --- |
| Mouse keys | Move the pointer with the number pad |
| Click by resting the pointer | Clicks when the pointer stays still for a moment |
| Hold to right-click | Holding the button down right-clicks |
| Press Ctrl to find the pointer | Shows where the pointer is |

## Hearing

**Flash for alert sounds** flashes the window or the whole screen when an alert sound plays.

## Using the keyboard

Every part of the desktop can be used with the keyboard. Arrow keys and <kbd>Tab</kbd> move around Start, Quick settings, notifications and the taskbar, <kbd>Menu</kbd> or <kbd>Shift</kbd>+<kbd>F10</kbd> opens the right-click menu of what has focus, and <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Tab</kbd> moves focus to the taskbar. [Keyboard shortcuts](/desktop/shortcuts/) lists the rest.
