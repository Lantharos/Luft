Press <kbd>Super</kbd> or click the Luft mark on the taskbar to open Start, the menu with your apps. It has a search field at the top, the apps below it, and your account and power buttons at the bottom. If you'd rather have only a search bar in the middle of the screen, choose [Gust](/desktop/gust/) instead. Settings, under Input, **Keyboard shortcuts** can add a shortcut for **Open Start** next to <kbd>Super</kbd>.

## Apps and folders

Start lists every app that isn't pinned to the taskbar, from A to Z until you rearrange them; after that it keeps your order and adds new apps at the end. Resting the pointer on an app says what kind of app it is, such as File Manager for Rover.

- **Rearrange** apps by dragging them.
- **Make a folder** by dragging one app onto another. Name it in the field at the top of the folder.
- **Take an app out** of a folder by dragging it onto **Apps** at the top, or with **Move to Apps** in its right-click menu. A folder that's empty disappears.
- **Pin an app** to the taskbar by dragging it there, or with **Pin to taskbar** in its menu. It leaves Start and comes back when you unpin it. Search still finds pinned apps.

## Shutting down, restarting and signing out

The power button at the bottom of Start shows Lock, Sleep, Sign out, Restart and Power off. Restart, Power off and Sign out ask once before they go ahead, say that open apps will close, and go ahead by themselves after a minute unless you cancel.

## Search

Start searches as you type. The best match sits on top and <kbd>Enter</kbd> opens it; the rest follow in groups.

<Shot name="start-search" alt="Start search working out a calculation" />

| What | Examples |
| --- | --- |
| Apps, by name, kind and keywords | `mail`, `files`, `terminal`. Apps you open often rank higher |
| What apps can do, from their menus | `private window`, `new window` |
| Open windows, by title or app | Picking one switches to it |
| Calculations | `2*(3+18)`, `15% of 80`, `80 + 15%`, `2^10`, `sqrt(16)`, `7 mod 3`. <kbd>Enter</kbd> copies the result |
| Answers about dates and times | `days until christmas`, `what day is 14 feb 2027`, `time in tokyo`, see [quick answers](/desktop/gust/#quick-answers) |
| Unit and currency conversions | `10 km to mi`, `100 f`, `1.5 GB in MiB`, `90 min`, `100 usd in eur`. Without a target unit, Start picks the usual one |
| Actions | `dark mode`, `night light`, `dnd`, `wifi off`, `bluetooth`, `airplane mode`, `keep awake`, `lock`, `sleep`, `sign out`, `restart`, `shut down` |
| Settings pages and sections | `night light`, `vpn`, `taskbar` |
| Recent files | The same list as Recent in Rover |
| Files and folders in your home folder | Several words narrow it down by folder, so `garden readme` finds `garden-planner/README.md` |
| Text inside files | Plain text, Markdown, code and other text files up to 1 MB, and the first 40 pages of PDFs. The matching line shows under the file |
| Clipboard history | Text you copied, by what it says, or everything with `clipboard`. Picking it pastes it |
| Emoji | `grinning`, `thumbs up`. Picking one types it |
| The web | Always last, and first when nothing else matches. Settings chooses the search engine |

Conversions cover length, mass, temperature, data sizes, time, volume, speed and currencies. Currencies use the day's reference rates, downloaded from Luft's own site, luft.computer, the first time you convert one on a given day and kept for offline use. The request says nothing about you or what you typed. Log out, restart and power off still ask first.

| Key | Does |
| --- | --- |
| <kbd>Enter</kbd> | Opens the best match |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Shows the best file in Rover |
| <kbd>Down</kbd> or <kbd>Tab</kbd> | Moves into the results |
| <kbd>Menu</kbd> or right-click | More for a result, such as **Show in Rover** or **Copy path** |
| <kbd>Esc</kbd> | Clears the search, then leaves a folder, then closes Start |

## When a file doesn't show up

Luft keeps an index of the names and text of files in your home folder. It works at the lowest priority and notes which folders change as you work, then catches up on them every five minutes (fifteen on battery), and when you open Start or plug in. A file saved a moment ago can take until then to appear. File contents are only read while plugged in; on battery, names stay current and contents wait.

The index leaves out hidden files and folders, other drives, anything a Git repository's `.gitignore` or an `.ignore` file excludes, cache folders such as `node_modules`, and read-only folders. Deleting `~/.cache/kestrel/search` makes it read everything again.
