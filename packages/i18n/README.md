# @luft/i18n

Translations for Luft's apps, Kestrel and Rust services, with [Fluent](https://projectfluent.org): locale negotiation, the Svelte `t()` store, the Vite plugin that bundles each language on its own, the `luft-i18n` crate and the checker behind `bun run check`.

How it fits together, how to write translatable code and how Weblate is set up are in [docs/translations.md](../../docs/translations.md).
