Settings reads and writes the same settings as the desktop, so a change made from Quick settings or the taskbar shows up here right away, and the other way round. Searching in [Start](/desktop/start-and-search/) finds Settings pages and sections too, such as "night light" or "fonts".

## Pages

The sidebar groups pages into Connections, Devices, Look & feel, Protection and System, with Apps under System. Pages for hardware you don't have stay out of the way: Bluetooth only appears with an adapter, Pen with a pen or drawing tablet, and the mouse and touchpad settings under Input only show what's connected.

| Page | What's there |
| --- | --- |
| Network | Wi-Fi, Ethernet, VPN, the firewall, airplane mode and proxy at a glance, each with its own page. The firewall page says which networks are home and which public, which apps other devices may connect to and on which networks, which extensions take connections, and which ports are open for services, on home networks or every network. Each connection has its own settings with its addresses, DNS, routes, whether it's metered, and a private hardware address for Wi-Fi |
| Bluetooth | Pairing and connecting, staying visible to nearby devices for a while, and bringing devices paired in Windows |
| Displays | Arrangement, mirroring, the main display, resolution, refresh rate, variable refresh, orientation, scale, brightness and Night Light. See [Displays](/personalize/displays/) |
| Sound | Output and input devices, volume and balance, louder than 100%, a volume and output for each app, device profiles and [system sounds](/personalize/sounds/) |
| Power & Battery | Power mode, battery health and a charge limit, the battery of connected devices, when the screen turns off and the computer sleeps, shutting down instead of running the battery flat during a long sleep, the power button, and the keyboard backlight |
| Input | Input sources, every keyboard shortcut including your own, [dictation](/desktop/dictation/), mouse and touchpad, key repeat, what Caps Lock and the Copilot key do, when the keyboard has one, and layouts and input methods made in [Keys](/apps/keys/) |
| Pen | Your writing hand, how the tip and eraser feel, what the pen's buttons do, its battery, and which display each drawing tablet draws on. See [Pen and drawing tablets](/desktop/pen/) |
| Printers | Printers on your network and by USB, which set themselves up, with their status, ink, queue and printing defaults, a test page, and adding one by its address or with a driver. See [Printing](/desktop/printing/) |
| Appearance | Light and dark, accent, wallpapers, app icons, cursors, fonts, text size and animations. See [Appearance](/personalize/appearance/) |
| Desktop | The taskbar, Start and [window tiling](/windows/tiling/) |
| Accessibility | Screen reader, zoom, large text, high contrast, reduce motion, on-screen keyboard, typing assist and pointing aids. See [Accessibility](/personalize/accessibility/) |
| Privacy | Screen lock and notifications on the lock screen, location, camera and microphone, file history, and cleaning up the trash, temporary files and old screenshots |
| Security | How protected the computer is, with pages for device encryption and its recovery key, passwords, SSH keys and passkeys, remote login over SSH, and protections such as Secure Boot, the security chip, games with anti-cheat and USB protection. See [Security](/system/security/) |
| Apps | Default apps, apps that start when you sign in, and which apps may use your location and camera |
| Accounts | Your picture, name and password, fingerprints, other people on the computer, cloud drives from iCloud Drive, OneDrive, Dropbox, Nextcloud and WebDAV, and the login screen: who is listed, automatic login, the default session and its wallpaper. See [Accounts and cloud drives](/files/cloud-drives/) |
| Language & time | Language, formats, the first day of the week, automatic time and time zone, and the clock's format |
| System | System updates, firmware updates, going back to the previous version, and switching between the standard and NVIDIA images. Its About page has the device's name and hardware, storage and whether internal drives mount when you sign in, other systems on the computer, software versions and recent problems. See [Updates](/system/updates/) |

## Display changes

Changes on the Displays page wait in a bar at the bottom until you choose **Apply**, so you can set resolution, scale and arrangement together. **Reset** throws them away.
