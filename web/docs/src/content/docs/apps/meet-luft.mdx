Meet Luft runs on Windows and Linux, not on Luft itself. It checks a computer, puts Luft next to the system already there, and restarts into it once to try or install it, without a USB stick. It also makes USB sticks.

<Shot name="meet" alt="Meet Luft, ready to try or install Luft" />

[Try Luft with Meet Luft](/start/meet-luft/) has the downloads and walks through each step.

## What it does

- **Checks the computer**: processor, firmware, drive layout, Secure Boot, TPM, BitLocker, Fast Startup, free space, graphics and Wi-Fi, and says what each means.
- **Makes room** next to Windows with Windows' own tools, or keeps Luft in a folder on Linux.
- **Restarts into Luft** once, to **Try Luft**, **Install Luft**, or on Linux **Replace** the old system.
- **Packs a moving box** of your files and settings from Windows for your new account.
- **Makes USB sticks**, and adds Luft to Ventoy sticks.
- **Gets the newest Luft** when a newer build is out.
- **Takes it all back out** if you change your mind.

## Shortcuts

| Shortcut | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Switch between releases and nightly builds |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> | Save the newest logs from Try Luft to the desktop |

When a step doesn't finish, Meet Luft says which one and offers to try again. On Windows it also keeps a log of what went wrong, to attach when you [report a problem](https://github.com/Lantharos/Luft/issues): type `%LOCALAPPDATA%\Sabine\logs` into File Explorer's address bar and it's the file called `meet`.
