Mailman keeps a local copy of every account, so opening, searching and sorting mail never waits on the network. New mail arrives as it's sent, and only changes are fetched. Archiving, deleting and moving mail happen at once while the server catches up in the background. If the server refuses, the mail comes back where it was and Mailman tells you why.

## Adding an account

Type your address and Mailman finds the settings for most providers by itself. IMAP and SMTP accounts work, and so do JMAP accounts. Passwords and sign-in tokens are kept in [Luft Keyring](/files/keyring/), where only Mailman can read them. Mailman runs in a sandbox that can go online and nothing more: it sees none of your folders, files you attach or save go through the file dialog, and attachments and links open in your other apps, outside the sandbox.

Mailman connects with encryption, and only picks encrypted servers when it finds the settings for you. If you set a server to **Not encrypted** yourself, Mailman asks before it connects, since your password and mail would cross the network readable by anyone on it.

An account can send from several addresses, each with its own signature and reply address. Replies go out from the address a message was written to.

## A calmer inbox

- **One inbox** for every account, with conversations grouped across folders.
- **The Screener** holds mail from people writing for the first time until you let them in.
- **Bundles** gather newsletters, receipts and updates, each with one-click unsubscribe.
- **Later** sets a conversation aside until later today, tomorrow morning, the weekend, next week or next month.
- **Reminders** bring a conversation back when nobody replied in a day, three days or a week.

## Writing

- Formatting as you type, in the style of Markdown, with pictures inline.
- Templates, and drafts saved to the server.
- **Undo send** for 5 to 30 seconds, and **send later**.
- Mailman opens `mailto:` links and `.eml` files.

## Reading safely

Each message shows in a frame of its own, where it can't run scripts or change anything around it. Remote pictures stay hidden until you allow them, for one message or always for that sender, and tracking pixels are removed. **Darken bright messages** tones down mail designed for a white page.

## Search

Search works offline across every account. Combine words with `from:`, `to:`, `subject:`, `is:unread`, `is:starred`, `has:attachment`, or `in:anywhere` to include Trash and Junk.

## In the background

Closing Mailman's window leaves it running in the background. It keeps every account in sync and tells you about new mail, using little memory while the window is closed. Opening Mailman or clicking one of its notifications brings the window back. To quit Mailman altogether, press <kbd>Ctrl</kbd>+<kbd>Q</kbd> or choose **Quit Mailman** in the command palette.

Add Mailman to the apps that start when you sign in, in [Settings](/apps/settings/) → Apps, and it starts in the background without a window.

## Smaller windows

In a narrower window the sidebar shrinks to icons and search opens in the command palette. When the window is too narrow for the list and the conversation side by side, a conversation takes the whole window and <kbd>Esc</kbd> goes back to the list. Mail designed for a wider page is scaled down to fit.

| <kbd>J</kbd> / <kbd>K</kbd> | Next and previous conversation |
| <kbd>E</kbd> | Archive |
| <kbd>#</kbd> | Delete |
| <kbd>B</kbd> | Set aside for later |
| <kbd>S</kbd> | Star |
| <kbd>R</kbd> / <kbd>A</kbd> / <kbd>F</kbd> | Reply, reply all, forward |

| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Send |
