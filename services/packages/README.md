# luft-packages

The system service that builds the packages Luft merges over its image as a system extension, for Schelf's `--system` and `repo`, and the activation service that brings each build into the running system. It also installs extensions from schelf.store, after checking the store's signature itself, into `/var/lib/luft/extensions` when the store approved the release to run inside Luft and into `/var/lib/luft/sandboxed-extensions` otherwise, and, while Developer tools is on, keeps what the person approved in Settings of extensions nobody reviewed in `/var/lib/luft/unreviewed-extensions` ([security](https://docs.luft.computer/extensions/how-extensions-run/)). `vm/run.sh` checks the latter in a VM. Apps reach it through the [luft-software crate](../../packages/system/software); how it builds, merges and removes packages is in [system packages](https://docs.luft.computer/developers/system/system-packages/).
