<kbd>Super</kbd> is the key with the Windows logo on most keyboards. Settings, under Keyboard, **Keyboard shortcuts**, changes any of these and adds your own.

## The desktop

| Shortcut | Does |
| --- | --- |
| <kbd>Super</kbd> | Start |
| <kbd>Super</kbd> twice | Turn the workspace into a [board](/windows/board/), or back |
| <kbd>Super</kbd>+<kbd>Tab</kbd> | [All windows](/windows/task-view/) |
| <kbd>Super</kbd>+<kbd>S</kbd> | Quick settings |
| <kbd>Super</kbd>+<kbd>N</kbd> or <kbd>Super</kbd>+<kbd>M</kbd> | Notifications |
| <kbd>Super</kbd>+<kbd>V</kbd> | Clipboard history |
| <kbd>Super</kbd>+<kbd>.</kbd> or <kbd>Super</kbd>+<kbd>;</kbd> | Emoji and symbols |
| <kbd>Super</kbd>+<kbd>I</kbd> | Settings |
| <kbd>Super</kbd>+<kbd>L</kbd> | Lock the screen |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Esc</kbd> | [Barometer](/apps/barometer/), the system monitor |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Delete</kbd> | Log out, after asking |
| <kbd>Super</kbd>+<kbd>Space</kbd> / <kbd>Shift</kbd>+<kbd>Super</kbd>+<kbd>Space</kbd> | Next or previous keyboard layout |
| <kbd>Super</kbd>+<kbd>P</kbd> | Switch displays: mirror, join, external only or built-in only |
| <kbd>Super</kbd>+<kbd>O</kbd> | Rotation lock |
| <kbd>Super</kbd>+<kbd>Esc</kbd> | Give shortcuts back to the desktop when an app, such as a remote desktop, captured them |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Tab</kbd> | Move keyboard focus to the taskbar |
| <kbd>Menu</kbd> or <kbd>Shift</kbd>+<kbd>F10</kbd> | The right-click menu of whatever has focus |

## Windows

| Shortcut | Does |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>Tab</kbd> | Switch windows on this workspace. In the switcher, <kbd>W</kbd> closes the selected window |
| <kbd>Alt</kbd>+<kbd>`</kbd> or <kbd>Super</kbd>+<kbd>`</kbd> | Switch between windows of the same app |
| <kbd>Alt</kbd>+<kbd>Esc</kbd> | Cycle windows directly, without the switcher |
| <kbd>Alt</kbd>+<kbd>F4</kbd> | Close |
| <kbd>Super</kbd>+<kbd>H</kbd> | Minimize |
| <kbd>Super</kbd>+<kbd>Up</kbd> | Maximize |
| <kbd>Super</kbd>+<kbd>Down</kbd> | Restore |
| <kbd>Super</kbd>+<kbd>Left</kbd> / <kbd>Right</kbd> | Snap to the left or right half |
| <kbd>Super</kbd>+<kbd>Z</kbd> | [Snap layouts](/windows/snap-layouts/) |
| <kbd>Super</kbd>+<kbd>Shift</kbd>+arrows | Move the window to the display in that direction |
| <kbd>Alt</kbd>+<kbd>F7</kbd> / <kbd>Alt</kbd>+<kbd>F8</kbd> | Move or resize with the keyboard |
| <kbd>Alt</kbd>+<kbd>F10</kbd> | Maximize or restore |
| <kbd>Alt</kbd>+<kbd>Space</kbd> | The window menu |

## Workspaces

| Shortcut | Does |
| --- | --- |
| <kbd>Super</kbd>+<kbd>1</kbd> … <kbd>9</kbd>, <kbd>Super</kbd>+<kbd>0</kbd> | Workspace 1 to 10 |
| <kbd>Super</kbd>+scroll | Next or previous workspace |
| <kbd>Super</kbd>+<kbd>Page Up</kbd> / <kbd>Page Down</kbd>, <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Left</kbd> / <kbd>Right</kbd> | Previous or next workspace |
| <kbd>Super</kbd>+<kbd>Home</kbd> / <kbd>End</kbd> | First or last workspace |
| <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>Page Up</kbd> / <kbd>Page Down</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>Left</kbd> / <kbd>Right</kbd> | Move the window to the previous or next workspace |
| <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>Home</kbd> / <kbd>End</kbd> | Move the window to the first or last workspace |

Scrolling over the taskbar switches workspaces too.

## On a board

| Shortcut | Does |
| --- | --- |
| <kbd>Super</kbd>+arrows | Pan, or with a window entered, move to the window next to it |
| <kbd>Super</kbd>+<kbd>=</kbd> / <kbd>Super</kbd>+<kbd>-</kbd> | Zoom in and out |
| <kbd>Super</kbd>+<kbd>Enter</kbd> | Enter the window you're using |
| <kbd>Super</kbd>+<kbd>Esc</kbd> | Step out of the window, back to the whole board |
| <kbd>Super</kbd>+<kbd>0</kbd> | Fit every window in view |

## Media and hardware keys

The volume, mute, microphone, play, pause, next and previous, brightness, keyboard backlight, touchpad, airplane mode, Bluetooth, calculator, mail, browser and power keys on your keyboard do what they say.

| Shortcut | Does |
| --- | --- |
| <kbd>Shift</kbd>+volume keys | Change the volume in small steps |
| <kbd>Alt</kbd>+volume keys | Change the volume without the click |
| <kbd>Shift</kbd>+brightness keys | Change the brightness of the current display only |

## Touchpad gestures

| Gesture | Does |
| --- | --- |
| Three fingers sideways | Next or previous workspace, following your fingers. A quick flick goes further |
| Four fingers up | Turn the workspace into a board, or close All windows |
| Four fingers down | All windows, or leave the board |
| Two fingers with <kbd>Super</kbd> held | Scroll between workspaces |

### On a board

| Gesture | Does |
| --- | --- |
| Three fingers | Pan around the board |
| Pinch | Zoom. Pinch out over a window to enter it, pinch in to step out |
| Three fingers sideways, in a window | Move to the window next to it |
| Three fingers down, in a window | Step out to the whole board |
| Tap with three fingers, then swipe | Move the window under your fingers |

## Touchscreen gestures

| Gesture | Does |
| --- | --- |
| Three fingers sideways | Next or previous workspace |
| Swipe up from the bottom edge | On-screen keyboard |
| Swipe down from the top edge | Leave full screen |
| Swipe up on the lock screen | Unlock |
