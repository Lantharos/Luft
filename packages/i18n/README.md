# @luft/i18n

Translations for Luft's apps, Kestrel and Rust services, with [Fluent](https://projectfluent.org): locale negotiation, the Svelte `t()` store, the Vite plugin that bundles each language on its own, the `luft-i18n` crate and the checker behind `bun run check`. `glossary` holds each language's terms and style rules for translators.

[Translating Luft](https://docs.luft.computer/developers/translating/) covers how it fits together, how translators work and how to write translatable code.
