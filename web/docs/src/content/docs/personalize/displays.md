Everything here is in Settings, under **Displays**. Changes wait in a bar at the bottom until you choose **Apply**.

## Scaling

Luft picks a scale for each screen by itself, from its size and resolution, so text is about the same size everywhere:

| Screen | Scale |
| --- | --- |
| 13" and 14" laptops | 150% |
| 15" to 17" laptops | 125% |
| Sharper laptop panels | 167% to 225% |
| 24" to 27" monitors | 100% |

Choose another scale under **Scale**, from the steps your screen supports. A scale you choose yourself is kept and never recalculated.

To make only text bigger, use **Text size** under [Appearance](/personalize/appearance/#text-and-fonts).

## Resolution and refresh rate

Each display has its resolution, refresh rate and orientation. **Variable refresh rate**, on displays that support it, can be on in games only or in every full-screen app.

## Brightness

Sliders change the brightness of the built-in screen and of external monitors that support DDC/CI. Hold <kbd>Shift</kbd> with the brightness keys to change only the display you're using.

## Night Light

Night Light makes colours warmer in the evening, which is easier on the eyes. It follows sunset and sunrise, or times you choose, with a warmth slider.

## Several displays

- **Arrange** displays by dragging them on the map, so the pointer moves between them where you expect.
- **Mirror displays** shows the same picture on all of them.
- **Main display** decides where the tray, status icons and new windows go.
- <kbd>Super</kbd>+<kbd>P</kbd> switches quickly between mirroring, joining, external only and built-in only, handy when plugging into a projector.

Each display gets its own taskbar, with Start, its apps and the clock, unless you choose otherwise in the [taskbar's options](/desktop/taskbar/#options). Start, Quick settings and notifications open on the display the pointer is on.

Move a window to another display by dragging it, with <kbd>Super</kbd>+<kbd>Shift</kbd>+arrows, or with **Move to Monitor** in the window menu. Only the main display switches [workspaces](/windows/workspaces/); windows on the others stay put. The [board](/windows/board/) uses the main display.

The login screen and the boot splash use the same arrangement as your desktop.
