Workspaces are separate desktops, each with its own windows. You never have to make one: there's always an empty workspace after the last one in use, and workspaces you empty disappear, up to ten in all.

## Switching

| | |
| --- | --- |
| Keyboard | <kbd>Super</kbd>+<kbd>1</kbd> to <kbd>9</kbd> and <kbd>Super</kbd>+<kbd>0</kbd> for workspaces 1 to 10, or <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Left</kbd> and <kbd>Right</kbd> for the one next to it |
| Touchpad | Swipe sideways with three fingers. The workspaces follow your fingers, and a quick flick can cross several |
| Mouse | Hold <kbd>Super</kbd> and scroll, or scroll over the taskbar |
| All windows | <kbd>Super</kbd>+<kbd>Tab</kbd> shows every workspace along the bottom; click one |

Past the first and last workspace, the desktop resists and springs back.

## Moving windows

- Drag a window onto a workspace in [All windows](/windows/task-view/).
- <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>Page Up</kbd> and <kbd>Page Down</kbd> move the window you're using to the workspace before or after.
- The window menu (<kbd>Alt</kbd>+<kbd>Space</kbd>) has **Move to Workspace** and **Always on Visible Workspace**.

## Workspaces and the taskbar

By default the taskbar lists windows from every workspace. To list only the current workspace's windows, turn on **Only list windows on the current workspace** in the [taskbar's options](/desktop/taskbar/#options).

## With several displays

Only the main display switches workspaces. Windows on other displays stay put whichever workspace you're on.
