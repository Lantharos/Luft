Luft is an operating system for PCs, built on Fedora. It has its own desktop, its own apps, and a startup that's signed from the moment you press the power button. It ships as one sealed image that updates as a whole and can always go back to the version before.

<Shot name="desktop" alt="The Luft desktop with Rover, Tern and Settings open" />

## What makes it different

- **Its own desktop.** [Kestrel](/desktop/overview/) has a taskbar, Start with search that finds apps, settings and the text in your files and does calculations and unit conversions, Quick settings, a [board](/windows/board/) where windows sit side by side on an endless canvas, snap layouts and workspaces. Its colours come from your wallpaper.
- **Its own apps.** [Settings](/apps/settings/), [Rover](/apps/rover/) for files, [Magpie](/apps/magpie/) for photos, videos, music and PDFs, [Mailman](/apps/mailman/) for mail, [Draft](/apps/draft/) for text and code, [Tern](/apps/tern/) for the terminal, [Schelf](/apps/schelf/) for more apps, and [Helium](/apps/helium/) for the web.
- **Updates you don't have to think about.** The system [updates as a whole](/system/updates/) at the next restart. If a new version doesn't start, Luft goes back by itself.
- **A startup you can trust.** A [signed startup](/system/security/), disk encryption that unlocks with the TPM, a keyring with passkeys, and USB devices held back while the screen is locked.
- **Easy to try.** [Meet Luft](/start/meet-luft/) gets a Windows or Linux computer ready without a USB stick, and Luft installs [next to Windows](/start/alongside-windows/) or [in place of another Linux](/start/replace-linux/), keeping your files.

## Built on Fedora

Luft uses Fedora's kernel, drivers and packages, so hardware that works on Fedora works on Luft. Every common video and audio format plays out of the box, decoded in hardware on Intel, AMD and NVIDIA graphics. Computers with NVIDIA graphics get [an image with NVIDIA's driver](/system/nvidia/), signed for Secure Boot.

Apps come from Flathub and as AppImages, and command-line tools from Fedora in a Toolbox container, all through [Schelf](/apps/schelf/). GNOME and KDE apps work as they do anywhere else.

## Getting started

1. Check the [system requirements](/start/requirements/).
2. Try it with [Meet Luft](/start/meet-luft/), or [from a USB stick](/start/usb-stick/).
3. Install it, and read about [the first start](/start/first-start/).
