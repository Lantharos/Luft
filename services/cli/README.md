# luft

Luft's command line: settings by the names Settings shows them, updates, the release channel, Developer tools, logs, bug reports, the extension development loop, and the same for AI agents over the Model Context Protocol with `luft mcp`. Changes to system settings are shown in one review in Kestrel and made only once someone approves them there. How it fits together is in [the luft command](https://docs.luft.computer/security/confirming/#changes-from-the-command-line); how to use it is on [docs.luft.computer](https://docs.luft.computer/system/terminal/).

```sh
cargo build --release -p luft-cli
target/release/luft --help
```
