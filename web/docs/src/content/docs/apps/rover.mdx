Rover is Luft's file manager. It's also the file dialog: when any app asks you to open or save a file, Rover's chooser appears, with the same sidebar, search and previews. Search for "files" in Start to find it.

<Shot name="rover" alt="Rover showing your home folder in the list view" />

## Finding your way

- **Tabs**, and list, grid and column views. Rover remembers the view for each folder. List columns can be sorted, resized and reordered.
- **The sidebar** holds your folders, Recent, Favorites, Trash, drives, [cloud drives](/files/cloud-drives/), network locations, and Windows' drive when it's on the same computer.
- **Search** by name or by what's inside files, narrowed by kind, date and size. <kbd>Ctrl</kbd>+<kbd>F</kbd> filters the folder you're in, and <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> searches everything inside it.
- **The details pane** and **Quick Look** (<kbd>Space</kbd>) preview pictures, video, audio, text, code, Markdown and PDFs without opening an app.
- **App icons**: AppImages, Flatpak bundles and Flatpak references show the icon of the app inside them.
- **Group** a folder by date or kind.

## Working with files

- Copy and move run in the background, with pause, cancel and a choice when names clash. Every file operation can be undone and redone.
- **Batch rename** a selection: change the case, replace text, or number them.
- **Compress** to zip or tar.zst, and **extract** zip, tar, 7z and single compressed files. Opening an archive extracts it next to itself and selects what came out.
- **Properties** shows permissions as a grid you can change, and the app that opens this kind of file. For a folder it adds up everything inside, counting a file it reaches twice, through hard links or a folder mounted in two places, only once, and leaving out cloud and system folders mounted inside it. For a drive it shows how much space is used and free.
- **Open in terminal** opens [Tern](/apps/tern/) in that folder.
- **Print** PDFs, pictures and text files, several at once as one document.

## Drives

USB drives and memory cards open as soon as you plug them in. The drives inside the computer that hold your files, formatted as ext4, Btrfs, XFS, F2FS, exFAT, FAT32 or NTFS, open when you sign in and sit in the sidebar with them. Luft leaves alone whatever belongs to a system: EFI and recovery partitions, swap, Luft's own partitions, other Linux systems and partitions marked not to mount on their own. Encrypted drives stay locked until you open them.

To keep internal drives closed until you open them, turn off **Mount internal drives when you sign in** in Settings, under System › About. For a partition that should always be at the same place, use **Mount at startup** in [Disks](/apps/disks/).

When Windows was hibernated or shut down with Fast Startup, its drives open read-only and a notification says so. To change files on them, start Windows and hold Shift while you choose Shut down.

When the files on a drive belong to another account, such as one from a system that was on the computer before, Rover says so and gives the command that makes them yours.

## Network locations

Rover connects to SFTP, SMB, FTP, WebDAV and NFS servers. Type an address such as `sftp://server` or `smb://nas/share` with <kbd>Ctrl</kbd>+<kbd>L</kbd>. Passwords are kept in [Luft Keyring](/files/keyring-and-passkeys/).

## Code folders

In a folder kept in Git, the details pane shows what changed, with diffs. You can commit changes and sync with the remote from there. Sync only runs when it can do so safely; with changes on both sides, it asks you to pull from a terminal first.

## Keyboard shortcuts

| Shortcut | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | Copy, cut, paste |
| <kbd>Space</kbd> | Quick Look |
| <kbd>Enter</kbd> | Open |
| Typing a name | Jump to the first file that matches |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> | List, grid, column view |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd> | Icon size in the grid |
| <kbd>Alt</kbd>+<kbd>P</kbd> | Details pane |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | Type a location |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> | Show hidden files |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | New folder |
| <kbd>Alt</kbd>+<kbd>Left</kbd> / <kbd>Right</kbd> / <kbd>Up</kbd> | Back, forward, parent folder |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> / <kbd>Ctrl</kbd>+<kbd>W</kbd> | New tab, close tab |
| <kbd>F2</kbd> | Rename, or batch rename a selection |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | Properties |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Print the selected files |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undo, redo |
| <kbd>Delete</kbd> | Move to the trash; inside Trash, delete for good |
