## Download

Get the ISO from [the download page](https://luft.computer/download#iso). There is one ISO for every computer: it carries both of Luft's images, the one with NVIDIA's driver included, and installs offline.

Until the first release, the ISO is the newest nightly build, and a computer installed from it keeps following the nightly builds. Only the newest few nightly ISOs stay available.

Each ISO has a checksum next to it, with `.sha256` added to its name, and that checksum is signed with [minisign](https://jedisct1.github.io/minisign/) in a `.sha256.minisig` file. To check a download:

```sh
minisign -Vm luft-1.20261020.57-nightly.iso.sha256 -P RWRz9rCK/H8Drrze/f851hxNNOH/D42kpyTMpXV7DT7QoUdCZySZwRWA
sha256sum -c luft-1.20261020.57-nightly.iso.sha256
```

The signature's trusted comment is the ISO's file name, so a checksum can't pass for another version.

## Write the stick

Use a stick of 4 GB or more. Everything on it is erased.

- [Meet Luft](/start/meet-luft/#making-a-usb-stick) downloads and writes it in one go, on Windows and Linux, and can add Luft to a Ventoy stick.
- Fedora Media Writer, balenaEtcher, or Rufus in DD mode work too.
- On Linux: `sudo dd if=luft-1.20261020.57-nightly.iso of=/dev/sdX bs=4M oflag=direct status=progress`, with the stick's device in place of `/dev/sdX`.

## Start from it

Start the computer from the stick with the firmware's boot menu, usually <kbd>F12</kbd>, <kbd>F11</kbd> or <kbd>Esc</kbd> while the maker's logo shows. Secure Boot can stay on.

The stick goes straight to Install Luft. If the screen stays dark, hold <kbd>Esc</kbd> while the stick starts for a menu with a basic graphics mode.

## Install Luft

1. **Language, keyboard and time zone.** Luft takes them from Windows when it's on the computer and Luft can read its drive, and the time zone from the network once you're online. When it couldn't guess, it says so, and you choose them yourself.
2. **Where Luft goes.**
   - **Alongside Windows** makes Windows' partition smaller and puts Luft in the space it frees. Drag the bar to share the drive; Windows keeps its files and at least 20 GB to grow. See [Installing alongside Windows](/start/alongside-windows/).
   - **Replace** puts Luft in place of a Linux system and keeps your files, accounts and settings. See [Replacing another Linux](/start/replace-linux/).
   - **Use a whole drive** erases one drive.
   - **Just try Luft** opens the desktop from the stick and changes nothing.
   - **Custom** opens Disks, where you can make free space your own way, then pick it.
3. **Encryption**, if you like. With a TPM, the disk unlocks by itself; without one, you choose a passphrase it asks for at every start. Keep the recovery key it shows somewhere other than this computer. Encryption can only be turned on here.
4. **Wi-Fi**, if you like. Luft is already copying by now.
5. **Your account**: your name, a user name and a password.
6. **Restart.** With Secure Boot on, Install Luft first shows the one blue screen that comes after the restart, and the code to type there. Take out the stick once the screen goes dark.

Copying starts as soon as you confirm where Luft goes and whether it's encrypted, and nothing on any drive changes before that. Luft needs at least 32 GB of space.

Install Luft picks the image with NVIDIA's driver when the computer has an NVIDIA graphics card. On the stick itself, NVIDIA cards run on the open-source driver, so setup looks the same everywhere.

## What goes on the drive

| Partition | Size | Holds |
| --- | --- | --- |
| EFI system partition | 1 GB | What starts Luft. A drive that already has one, such as Windows', shares it when it has 1 GB or more |
| Luft startup | 2 GB | Luft's signed startup images, when the drive's EFI system partition is smaller than 1 GB, as Windows' usually is |
| Luft | The rest | The system and your files, on btrfs |
