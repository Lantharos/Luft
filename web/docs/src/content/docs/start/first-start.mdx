## The blue screen

With Secure Boot on, your computer asks once whether to trust Luft, on a blue screen right after the restart. Install Luft shows you this screen before the restart, with an eight-digit code. When your computer already trusts Luft's key, from an earlier install, there's no blue screen and no code.

1. At *Press any key to perform MOK management*, press any key within a minute.
2. Choose **Enroll MOK**, then **Continue**.
3. At *Enroll the key(s)?*, choose **Yes**. The screen picks No first.
4. At *Password:*, type the eight digits and press <kbd>Enter</kbd>. Nothing shows while you type, and a wrong code says *Password doesn't match*.
5. Choose **Reboot**.

The blue screen is in English and only takes the arrow keys, <kbd>Enter</kbd> and digits.

<Shot name="setup-installed" alt="Install Luft showing the steps for the blue screen and the code to type" />

If you miss it, nothing breaks. The firmware moves on to an entry called *Luft without its key*, which starts the same Luft through Fedora's signed boot loader. The first start that way can't use the TPM, so an encrypted disk asks for its recovery key or passphrase once. Luft asks again with the same code at the next starts, up to three times, and shows the code before each restart. After that, you can ask again from Settings, under Security. [Boot and recovery](/developers/system/boot/#before-lufts-key-is-trusted) explains how this works.

## Signing in

Luft starts at the login screen with the account you made. Sign in with your password, and Install Luft opens over the blurred wallpaper for the last steps:

1. **Your network**, when the computer is connected. Choose Home for a network you trust, so your other devices can find this computer, or Public for one like in a café. See [Home and public networks](/system/security/#home-and-public-networks).
2. **Secure Boot**, only when the blue screen was skipped. Install Luft shows the code and restarts to ask again.
3. **Fingerprint**, if the computer has a reader. Add a finger to sign in and unlock with it.
4. **Done.** The desktop opens, or the computer restarts when a step needs it.

Every step but the network can be skipped. Networks are in Settings under Network → Firewall, Secure Boot under Security, and fingerprints under Accounts. [Security](/system/security/) explains what each protects.

## What Luft picks for you

- **Display scale**, from the screen's size and resolution. See [Display scaling](/personalize/displays/#scaling).
- **Tap to click** on touchpads.
- **Region formats**: when your time zone is in another country than your language, your formats follow the time zone's country, so a German time zone starts the week on Monday. You can change the first day of the week in Settings, under Language and time.

All of these can be changed in Settings.

## Before the desktop appears

The first time you sign in, Luft adds [Helium](/apps/helium/), its web browser, to your account, even when you're offline. If you came from Meet Luft, it also removes Meet Luft's partitions or folder and grows into their space.
